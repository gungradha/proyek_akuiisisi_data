# proyek_akuisisi_data

Reproducibility atau keterulangan sangat penting dalam akuisisi data karena memungkinkan proses pengumpulan, pengolahan, dan analisis data dilakukan kembali dengan langkah yang sama sehingga hasilnya dapat diperiksa dan dipercaya. Dengan adanya reproducibility, peneliti atau anggota tim dapat mengetahui dari mana data berasal, bagaimana data dikumpulkan, perubahan apa saja yang dilakukan, serta alasan di balik perubahan tersebut. Hal ini juga membantu mengurangi kesalahan, mempermudah kerja sama, dan menjaga konsistensi hasil penelitian. Sebagai contoh nyata, dalam pengumpulan data harga bahan pokok di pasar, seorang mahasiswa mencatat harga beras, gula, dan minyak goreng dari beberapa pasar untuk dianalisis. Jika mahasiswa tersebut mendokumentasikan tanggal pengumpulan, lokasi pasar, sumber data, dan metode pencatatan, orang lain dapat mengulangi proses yang sama untuk memeriksa apakah hasilnya sesuai. Sebaliknya, tanpa dokumentasi yang jelas, hasil pengumpulan data akan sulit diverifikasi dan dibandingkan. Penggunaan Git dan GitHub juga membantu menjaga reproducibility karena perubahan kode, dokumentasi, dan berkas proyek dapat dicatat dalam riwayat versi. Dengan demikian, reproducibility membuat proses akuisisi data lebih transparan, terstruktur, dan dapat dipertanggungjawabkan.
